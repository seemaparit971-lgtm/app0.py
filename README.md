# Student Marks Management System

## Project Description
This is a simple Python program to manage student marks. It accepts student details and marks for three subjects, calculates the average, and assigns a grade based on the average marks.

## Features
- Enter student name.
- Enter department and semester.
- Enter marks for three subjects.
- Validate marks between 0 and 100.
- Calculate average marks.
- Display the student's grade.

## Technologies Used
- Python
- Git and GitHub
- Docker

## Grade Calculation
- Average >= 90: S Grade
- Average >= 80: A Grade
- Average >= 65: B Grade
- Average >= 50: C Grade
- Average >= 40: D Grade
- Average < 40: F Grade

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python app.py
```

## Conclusion
This project demonstrates basic Python programming, conditional statements, input validation, and grade calculation.
